CoC FvTT 퀵 가이드

⚙️ 1. 기본 설정

  • 픽셀 해상도 비율 조정, 좌클릭으로 오브젝트 선택해제 ➔ 체크 유지 (나머지 끔)
  • 성능 모드: PC 환경에 맞게 타협 (낮음~최대)
  • 최대 FPS: 30FPS 이상 권장

🗣️ 2. 조작 및 대화

  • 이동: WASD 키를 사용하여 토큰 이동
  • 대화: 채팅창 하단 맨 우측에 있는 [Public as Character] 선택 후 입력 (캐릭터 토큰 이름으로 말하기)

⚔️ 3. 판정 및 전투

  • 기능 판정: 시트에서 기능 클릭 ➔ 채팅창에 테스트 창이 올라오면 그곳에서 주사위 굴리기
  • 행운 소모: 판정 실패 시, 채팅창에 뜬 결과를 클릭하고 [행운 소모] 버튼을 눌러 적용
  • 전투 1 (대상 지정): Alt + 좌클릭으로 공격 대상 지정
  • 전투 2 (행동 선택): 시트의 [전투] 탭에서 원하는 행동(액션) 클릭
  • 전투 3 (굴림): 채팅창에 나타난 메시지에서 주사위 굴리기 진행

📜 4. 핸드아웃 (단서)

  • 우측 저널(책 아이콘) 탭에서 확인
  • 창의 우측 하단을 드래그하여 자유롭게 크기 조절 가능

⌨️ 5. 필수 단축키

  • R : 거리 측정 자 ↔ 토큰 선택 도구 전환
  • C : 내 캐릭터 시트 열기/닫기
  • Alt + 좌클릭 : 공격 대상 지정 (타겟팅)
